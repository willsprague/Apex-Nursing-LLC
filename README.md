# Apex-Nursing-LLC

Repo for Apex Nursing LLC (brand: Apex Nurse Partners).

## What's here

- `site/index.html`: homepage draft. A single self-contained page with the logo, three facility-type tabs (long-term care, hospitals, home health and clinics), and a facility request form. The form is a preview only and is not connected to an inbox yet.

## Brand name

The name, descriptor, and region are set in one `BRAND` block at the bottom of `site/index.html`. The logo images are embedded in the page, so a rename also needs new logo files.

## Rules for this repo

- Never commit passwords, API keys, or facility or worker data. Keys belong in the hosting provider's settings, and data belongs in the database.
